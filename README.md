# Kwok-Wing Tsoi's website

This is the source folder for:

<https://kwokwingtsoi.github.io/kwtsoi.github.io/>

## Easy folder map

```text
kwtsoi-website/
├── index.html          ← the complete homepage
├── style.css           ← colours and visual design
├── files/              ← papers and other downloads
│   └── 2603.11615v1.pdf
├── EDITING_MAP.md      ← where and what to edit
├── MAINTENANCE.md      ← plain-language editing and publishing guide
├── KW_TSOI_WEBSITE_GUIDE.md ← complete handbook for KW Tsoi
└── README.md           ← this map
```

For routine changes, start with `EDITING_MAP.md`. Edit `index.html` for words
and links, and use `files/` for documents. See `MAINTENANCE.md` for the quick
workflow or `KW_TSOI_WEBSITE_GUIDE.md` for the complete handbook.
